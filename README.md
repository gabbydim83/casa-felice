# Casa Felice — Explore Brașov Template Type 1

Demo website for a guesthouse / villa with multiple rooms.

## Local preview (Windows)

Double-click `serve.bat` if Python is installed, then open:

http://localhost:5500

Alternative in VS Code: install/open Live Server and launch `index.html`.

## Structure

- `index.html` — self-contained HTML + CSS + JavaScript
- `images/` — Casa Felice photos
- `serve.bat` / `serve.ps1` — local preview helpers

The Explore Brașov sections are structurally ready. The central GitHub data source will be connected after the repository/base URL is confirmed.
